## 测试矩阵要点（改规则/改引擎必须对照）

**combos（王规则）**：3+鬼→对3；单鬼/双鬼/纯王炸非法；3,4,鬼→345；4,5,鬼,鬼→4567；K,A,鬼→QKA；10,J,Q,鬼,K→10JQKA；顺子含 2 非法；3,3,4,4→连对；3,鬼,4,4→3344；2,2,鬼→炸弹 3×2；13 张非法；7,7,7,7,8 非法。

**canBeat（混合管牌）**：5 压不了 3；对7 压不了对5；单2 压 A；2 压不了对子；对2 只有炸弹可压；3×A>3×K；4×5>3×K（张数优先）；456/567 接 345、**678 接不了 345**（起点不在窗口内）；6789 接 3456；4 张顺压不了 3 张顺；炸压顺、顺压不了炸。

**engine**：种子模拟 2-6 人各跑数百局（恰好一个赢家、零和、牌守恒 = 手牌+桌面+展示池+牌堆+弃牌 ≡ 162；留2规则下赢家可能是唯一幸存者）；纯王 leader 死锁守卫；被技能否决到无牌可出的跟随者可以过（技能优先）；**全员纯王 → 流局**（winnerId=null、全 0 分）；牌堆耗尽摸 0 继续打；出完即胜（即使别人理论上能压）；**留2规则**：最后一手单2/对2（含 2+鬼）判负淘汰、牌局继续、单2 留在桌面轮到下家，2炸正常获胜；手牌超 20 淘汰、仅剩一人获胜、淘汰者被回合跳过；询问挂起时动作全部被拦、resolveAsk 错误回答者/失效 askId 被拒、多阶段询问重挂起 askId 自增；插队（cutIn）接受/拒绝/非法响应（响应牌需含与被压牌同花色的真牌）、接完从**无名的下家**继续（跳过中间玩家）；**无名加牌**：单张/多张同花色响应均触发（插队或普通响应），X = 响应牌中同花色真牌点数总和（用户示例 ♠5♥6♦7 ← ♣6♦7♠8 → 15）、异花色不触发、轮转从无名下家继续；翻牌池未清空抛错；**翻牌公开**：revealTop 广播 cards:revealed（含 purpose）、挂起期间旁观快照可见 revealed 池、收尾清空。

**roles**：每角色精确效果（含 setup 私有状态变化、ask 多阶段、announce 文案）；同事件双角色钩子按 priority→座位序执行；setup 状态快照往返；非法角色定义被 registry 拒绝；**技能优先**：基础规则判违法的出牌经 `allowAnyway` 合法执行、基础规则判合法的出牌被 `ok:false` 否决。2026-09-28 修复新增：茄汤一元炸/二元炸成炸、二元压一元、三元炸弹压二元、无黑牌不发动；骚骚盲抽答案只带 cardIds（客户端真实载荷）交换仍执行；巨石判定失败判定牌摸回且展示区清空；黑脸连续 13 黑 1 红全部摸回、红牌进弃牌堆、牌守恒。2026-10-01 无名触发条件修正新增：单张同花色响应触发（X = 单张点数）、单张异花色不触发、多花色响应 X 只算同花色牌（用户示例 → 15）、3 人局单张同花色插队。同日骚骚换牌视为过牌新增：2 人局换牌后直接轮末（对方摸 1 张起新回合）、3 人局中间人已过 → 换牌后轮末、3 人局中间人已接 → 本轮不结束轮到出牌者继续接、起牌者 endTurn 仅换轮（引擎守卫）。同日骚骚同花色自由选择新增：同花色给牌出现 choice 询问（换 1/2 张，五段询问）、自选换 2 张拿目标 2 张且手牌不足 2 张者不进候选、仅同颜色（不同花色）不出现选择直接选目标、选目标阶段弃权后下次发动可重新走完整流程（中间态清理守卫）。

**server**：建房/加入/重名/重连（secret 校验）；房主才能开始；全员 ready 才能开始（含房主）；**首局先手 = 房主**；2-6 人边界；rematch 全票回房间（不自动开局、全员未准备、可重选角色）后重新开局先手给上局赢家、分数保留；JsonFileScoreStore 读写（临时目录）；技能询问：轮末最后出牌者收到观股询问、同意大涨每人 1 张、超时 15s 自动弃权正常摸牌、重连后未决询问重发；模拟打完整局时询问一律弃权、出牌被否决逐个尝试。

## 命令

```bash
npm test                # Vitest 全绿（shared + server）
npx tsc -p shared && npx tsc -p server && npx tsc -p client   # 三包类型检查
npm run build           # client 构建
npm run smoke           # 双客户端 E2E：建房→选角→开局→自动打完→记分落盘→重连
```

## 防抖动（flake）纪律

- 任何测试改动后，**服务器套件连跑 12-15 次**（`for i in $(seq 1 15); do npx vitest run server --silent || break; done`）确认稳定才交付
- 测试断言一律读**观察者 socket** 的广播（被断连/掉线的玩家 socket 收不到事件，读它必翻车）
- 随机相关的测试：要么种子固定，要么接受"任何合法结果"（不断言具体牌面，只断言不变量）

## 烟测（smoke.ts）要点

- 监听器必须在 `room:rejoin` **ack 之前**注册（快照先于 ack 到达）
- 2 人局自动打（最小组合策略）收敛慢，步数上限放 300
- 角色：A = 首席（skywalker，蛋神/仁德），B = 第六席企鹅（cs-champion，骚骚）
- 技能链路：B 接牌时发动一次【骚骚】→ 收到 game:skill-ask → 弃权 → 对局继续；对局中任何询问一律弃权（模拟不思考策略的机器人）
- 出牌被技能否决（仁德最后一张 Q）→ 逐个尝试下一个组合，全被否 → 过
- 校验：按查看者过滤手牌（A 看不到 B 的牌）、非法出牌回执、零和记分、scores.json 增长、secret 重连、错误 secret 拒绝

## 手工验收清单（每次大改后过一遍）

1. `npm test` 全绿 + 三包 tsc + build + smoke
2. `npm run dev`，同机两个浏览器窗口完整对局：单/对 +1、2 压一切、三张炸弹、王补顺子预览、过牌、轮末摸牌、终局记分、**首局先手=房主**、再来一局全票后回房间（重选角色）→ 重新开局先手给上局赢家
3. 技能弹窗：观股确认/大涨大跌、茄汤亮牌、骚骚换牌四步、巨石选花色、手牌超 20 淘汰提示
4. 手机（同 WiFi 访问 `http://电脑IP:5173`）与电脑对打；游戏中途刷新 → 恢复座位 + 未决询问重弹
5. 断网 → 掉线标 → 30s 自动过；重连恢复
6. 重启服务后战绩仍在（scores.json）
