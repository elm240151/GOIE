# 需求与定稿规则

## 项目背景

用户与朋友线下玩自创的「干瞪眼」变体：干瞪眼规则 + 每人选一个角色获得技能（三国杀风格，战报.xlsx 中约 40 个角色）。目标是把这套玩法搬到线上，让手机/电脑浏览器联机玩。

## 目标与优先级

1. **干瞪眼游戏框架**（规则引擎 + 房间 + 出牌交互）——已完成
2. **角色技能系统极好扩展**：加一个角色 ≈ 丢一个文件（见 docs/04-role-dev-guide.md）
3. 平台：网页版，Node.js + Socket.IO，房间号加入；先本地/局域网玩，结构预留免费云部署
4. 2-6 人；UI 全中文

## 定稿规则（已与用户逐条确认，改规则必须先问用户）

### 牌库与发牌
- 三副 54 张含大小王 = **162 张**
- 先手发 **6 张**，其他人 **5 张**；先手 = 上局赢家（**首局 = 房主**，2026-09-27 用户定稿）
- 点数：3 < 4 < … < K < A < **2**（2 最大）；王无点数、纯百搭

### 牌型
| 牌型 | 规则 |
|---|---|
| 单张 | 任意一张真牌 |
| 对子 | 两张同点数，王可补 1 张（7+鬼=对7） |
| 顺子 | 3 张起连续，**不含 2**，王可补缺 |
| 连对 | 2 对起连续对子（3344），**不含 2**，王可补缺 |
| 炸弹 | **3 张起**同点数（三张即炸），王可补张数；上限 12 张 |

- **王不能单独打出**；双王/纯王组合不合法（至少 1 张真牌）
- **百搭顺子解析（确定性）**：先补内部缺口 → 从最高真牌向上延伸（不超 A）→ 从最低真牌向下延伸（不低于 3）。例：4,5,鬼,鬼→4567；K,A,鬼→QKA。2 永不作百搭目标

### 管牌（混合严宽）
- 单张/对子：**恰好大一级**（单3→单4，对5→对6）
- 例外：**2 无视 +1**——单2压任何单张、对2压任何对子；**仅炸弹可压 2**
- 顺子/连对：**同长度，起点必须落在上家牌型的点数窗口内**（不能跳远）：345 只能被 456/567 接，678 不能接；连对按对子粒度同理
- 炸弹可炸一切；炸对炸：**张数多的大，张数相同比点数**（4×5 > 3×K；3×2 > 3×A）

### 流程与记分
- 不能管：直接过不摸牌；**可以自愿过**（有牌能管也可选择过）
- 一轮结束（除出牌者外都过了）：出牌者摸 1 张，继续先出下一轮
- **出完手牌立即获胜**（即使别人还能压）
- **留 2 规则（2026-10-03 用户改稿）**：**禁止以单 2 或对 2 打完手牌**（2+鬼 也算对 2）——不判负、不淘汰，玩家留在局中（可继续被技能加牌等）；只剩单 2/对 2 时死锁守卫自动过、压不了就过牌；2 炸（3 张及以上 2）不受影响。本质是限制"留 2 随意压单牌"破坏体验，而非留 2 直接判负（原 2026-09-28 判负淘汰版本作废）
- 记分：**赢家 +(人数−1)，每个输家 −1**（零和；3 人局即 +2/−1/−1），无翻倍，跨局累计
- **再来一局**：终局后全员投票，全票通过 → 回到房间界面，可**重新选角色**、重新准备，房主开局（先手仍给上局赢家；2026-09-27 用户定稿）
- **流局**（规则未覆盖的边界，已按"平局"实现）：全员手牌只剩王/单 2（含 2026-10-03 留 2 改稿后的禁止收尾死锁）、无人能起牌时，无赢家、每人记 0 分，可再来一局。若用户线下有别的玩法可改（见 engine.finishDraw）

### 手牌上限与淘汰（已与用户逐条确认）
- **手牌上限 20 张**：不特殊说明时，所有人上限 20
- **超过 20 直接淘汰**：手牌进弃牌堆、记 −1、仅剩一人时该玩家立即获胜
- 座位保留但跳过（淘汰者不再轮到，仍显示在牌桌上）
- 角色技能造成的"判定牌"（如黑脸）当轮豁免上限，下轮重新计

### 技能相关通用规则（已与用户逐条确认）
- **大王红、小王黑**（涉及花色的技能判定以此为准）
- 判定中的王按颜色双花色（2026-10-03 用户确认）：打出的牌里的王（含百搭位）按对应颜色提供两种花色（小王 = ♠♣、大王 = ♥♦）；翻出的判定牌是王同样按双花色判定（不再「翻到王必然失败」）
- 插队（无名）：插队跳过了被响应者与无名之间的玩家；接完从**无名的下家**继续（2026-10-01 用户修正：原"被响应者下家"作废）；被响应者摸 X 张；插队适用于全部牌型（炸弹也适用）；2 人局无名就是下家，不触发插队
- 无名触发条件（2026-10-01 用户澄清）：**响应牌中有与被压的牌相同花色的真牌**即触发（单张也算，插队或普通响应均可）；X = **响应牌中同花色真牌的点数总和**（例：被压 ♠5♥6♦7、无名出 ♣6♦7♠8 → X = ♦7+♠8 = 15；♣6 不算）。原"响应牌含同花对子、X=解析后点数求和"作废
- 黑脸/观股的"牌权"= 轮末最后出牌者摸牌时刻（首局先手不算）
- 骚骚换牌**视为过牌**（2026-10-01 用户确认）：换牌取代出牌阶段、等同点过——其余人全过则本轮结束（最后出牌者摸 1 张并起新回合；2 人局即对方直接摸 1 张起新回合），否则轮到下家正常接牌
- 骚骚同花色选择（2026-10-01 用户确认）：**同花色也算同颜色**——同花色 2 张给牌时可自由选择换对方 1 张还是 2 张；仅同颜色（不同花色）只能换 2 张
- 巨石：驱逐 = 淘汰该出牌者 + 技能所有者获得牌权；驱逐优先于获胜判定；判定次数上限 = 玩家数+2；可选发动，放弃不消耗次数；判定失败判定牌摸回（当轮豁免手牌上限）；**触发按实体牌判断**——修勾答疑改点只改桌面判定点数，不改变「打出的是 2/炸弹」这一事实；**触发牌型（2026-10-03 用户确认）**：正序单 2/对 2、**倒序镜像成单 3/对 3（倒序下 2 不触发）**、炸弹、首席的 Q、橐驼的单王与**对王（一对王直接打出也要判定；王当百搭配牌打出不触发）**——正倒序都触发；**触发按「打出这一手时」的牌序**（洄游先判后切：海棠的牌切换牌序，切换前的顺序决定哪张触发）；判定花色：翻出的牌是王按颜色双花色（小王 ♠♣、大王 ♥♦）
- 修勾答疑：任何人（含自己）打出 ≥2 张的牌型（对/顺子/连对/炸）时可为其答疑——不改变牌型，把桌面这手牌的判定点数改为修勾任选的 3~A（顺子/连对改的是起点 = 最低点数；**选项限制为合法起点窗口**（2026-10-03 用户确认）：正序顺子起点 ∈ [3, 15−长度]、倒序 ∈ [3+长度−1, 14]、连对 span = 长度/2）；牌面保留原牌但牌型标签直接改写为新点数主显（金色），原点数以「改判：原X」小标展示；每回合（轮）限一次，弃权不消耗；只影响判定，实体牌不变
- 修勾狂吠：出牌后可以立刻按正常管牌规则压自己打出的牌（2 压一切等规则不变），可连压到放弃或压不了；同样受留 2/留 3 禁止收尾约束
- 橐驼地坛：每回合（轮）限一次，**别人**（不含自己）打出 ≥3 张的牌型（炸弹/顺子/连对）时可判定：翻一张牌，花色与这手牌中任意一张真牌相同 → 使其陷入红楼梦（下回合（轮）不得出牌——不能起牌/响应/插队/狂吠/补打，轮到他自动过、照常摸牌；若其获得本回合牌权，由橐驼取而代之：橐驼摸牌 + 起新回合）；弃权不消耗次数；判定失败消耗次数且判定牌弃置；**王按颜色双花色参与判定（2026-10-03 用户确认）**：打出的牌里的王按 ♠♣/♥♦ 算、翻出的判定牌是王同样按双花色判定（不再「判定牌是王算失败」）；牌堆已空视为未判定（不消耗）
- 橐驼诅咒：锁定技——橐驼的王可以直接打出（单王牌型，点数视作无穷）：正序压过一切单张（含 2）、**倒序同样压过一切单张（含 3，2026-10-03 用户确认：倒序下无穷小才是最大的）**，只有炸弹能压（王压不了王）；**一对王可直接打出（对王牌型，2026-10-03 用户确认）**：压一切对子（正序含对 2、倒序含对 3），只有炸弹能压、王压不了王，正倒序一致
- 亡语（2026-10-03 新概念）：技能在有人打完手牌后仍能生效、有机会阻止其立即取胜——引擎的打断钩子（onPlayInterrupt）跑在获胜判定之前，判定成功让打光者手牌重新非空即取消获胜。雪灾巨石（驱逐优先于获胜判定）与楠王旺旺均属亡语
- 楠王旺旺（亡语）：每回合（轮）限一次，有人压楠王的牌时可判定：翻一张牌，非红桃 → 压牌者进入成功班、摸 3 张手牌（打光了手牌也无法立即获胜）；红桃（大王按 ♥♦ 算红桃）→ 无事发生、照常获胜；判定牌一律弃置（成败都是）；王按颜色双花色（小王 ♠♣ 非红桃、大王 ♥♦ 红桃）；弃权不消耗、发动即消耗；牌堆已空视为未判定、不消耗；触发 = 桌面归属者是楠王时被响应（归属改写后视作楠王的牌被压同样触发；插队压的是响应者的牌、不会指向楠王）；与巨石同场**旺旺先判**（2026-10-03 用户确认，priority 100）
- 楠王回味：锁定技——楠王压牌时被压者摸牌，张数 = 两人所打牌点数总和差的绝对值、至多 3 张（差为 0 不摸）；点数计算（2026-10-03 用户确认）：2 记 2、A 记 1、其余按牌面（J=11 Q=12 K=13）；王当百搭按所当点数，单王/对王视为无穷（差必封顶 3）；加的牌不豁免手牌上限
- 轴承端庄（2026-10-04 用户确认）：轮到自己响应时可翻面一张上次打出的牌并接牌（**翻 + 出是一次动作**；翻面牌以牌背明置桌旁，其余玩家可见翻面）。两种情况：①桌面只有一张 → 翻掉整手、接**上一手**的牌（按正常管牌规则：恰好大一级/2 压一切/炸弹；前面只有这一手则无法发动）；②桌面多张 → 翻其中一张，剩余仍是合法牌型 → 按正常管牌规则接（对5翻一张剩单5接单6）；剩余非法（如 345 翻 4 剩 35）→ 轴承打**后继**（每张剩余牌按原牌型中所当点数 **±1：正序 +1、倒序 −1**（倒序镜像，与「恰好小一级」等同源，2026-10-04 用户最终确认），王按所当点数、响应可用王补缺，如 35 → 46）或炸弹——后继接出的桌面是特殊牌型「翻面接」（只有炸弹能压），**他人若无特殊技能只能用炸弹响应**；后继越界（正序剩 2 / 倒序剩 3）时只有炸弹能压。翻面只对轴承自己的出牌回合生效：翻面了但自己没接 → 自动翻回、不影响后续接牌
- 轴承窃笑（2026-10-04 用户确认）：主动技——轮到自己时（每轮一次，弃权不消耗）可私密查看一名玩家手牌；**被查看者收到提示**（其余人不知道）
- 惰戈亢奋（2026-10-04 用户确认，锁定技）：有人打出的手牌点数和 ≥20 时（点数和 = 牌面点数：2 记 2、A 记 1、J=11、Q=12、K=13；王按所当点数、单王/对王视为无穷），该手牌在**打出那一刻**即视作惰戈打出——与阿色再问不同（再问是技能释放有间隔、起手先算实际出牌者），亢奋不触发实际出牌者的技能（含海棠洄游不切换），接牌轮转从惰戈下家继续（原出牌者不跳过、仍可接），巨石/地坛等判定对惰戈生效，轮末无人再接则惰戈获得牌权，打完手牌仍按实际出牌者获胜；适用于一切打出（正常出牌/插队/狂吠连压/翻面接/茄汤强制）；惰戈淘汰后失效
- 惰戈法音（2026-10-04 用户确认）：惰戈打出的牌（含亢奋归属）中至少两种不同花色（王算其包含的两种花色：小王 ♠♣、大王 ♥♦）时，惰戈可选择一位角色弃置一张牌——被弃者自选弃哪张（进弃牌堆）；惰戈手牌 ≤3 时不能选自己（仍可选别人）；每次打出都触发、无次数限制；弃权/超时无事发生；priority 950 先于阿色再问（900）：同一手牌先问法音，弃权后仍触发再问
- 玊两倍（2026-10-04 用户确认，锁定技）：初始手牌、手牌上限、所有从牌堆的摸牌数量均为正常数量的两倍——初始手牌 = 发牌张数 ×2（先手 6×2=12、其余 5×2=10）；手牌上限 20×2=40（超出照常淘汰）；轮末补摸/技能摸牌等一切从牌堆摸的牌 ×2；**拿回特定牌与别人给牌不翻倍**（判定牌摸回、展示区拿牌照常）
- 玊呕哑（2026-10-04 用户确认）：轮到自己接牌时可打出**包含桌面那一手牌全部实际点数**的任意合法牌型，无视管牌规则——「该点数」= 那手牌实际含的每个点数（逐张实体判定，王按所当点数、答疑改点不改实体、与巨石同口径）；只在自己接牌时可用（不插队）；王可以补缺；单王/对王桌面（点数无穷）不可发动；起牌（无桌面）不可发动；无次数限制；留 2/留 3 禁止收尾照常生效；打完照常获胜

## 技能优先原则（用户明确要求）

**技能与基础规则冲突时，技能生效。** 实现：引擎每个判定点走"基础规则校验 → 角色钩子覆写"两段管线——钩子可以 `allowAnyway` 放行基础规则禁止的动作，也可以 `ok:false` 否决基础规则允许的动作。引擎不做任何"哪个优先"的特判（详见 docs/04）。
