# 需求与定稿规则

## 项目背景

用户与朋友线下玩自创的「干瞪眼」变体：干瞪眼规则 + 每人选一个角色获得技能（三国杀风格，战报.xlsx 中约 40 个角色）。目标是把这套玩法搬到线上，让手机/电脑浏览器联机玩。

## 目标与优先级

1. **干瞪眼游戏框架**（规则引擎 + 房间 + 出牌交互）——已完成
2. **角色技能系统极好扩展**：加一个角色 ≈ 丢一个文件（见 docs/04-role-dev-guide.md）
3. 平台：网页版，Node.js + Socket.IO，房间号加入；先本地/局域网玩，结构预留免费云部署
4. 2-6 人；UI 全中文

## 定稿规则（已与用户逐条确认，改规则必须先问用户）

### 牌库与发牌
- 三副 54 张含大小王 = **162 张**
- 先手发 **6 张**，其他人 **5 张**；先手 = 上局赢家（**首局 = 房主**，2026-09-27 用户定稿）
- 点数：3 < 4 < … < K < A < **2**（2 最大）；王无点数、纯百搭

### 牌型
| 牌型 | 规则 |
|---|---|
| 单张 | 任意一张真牌 |
| 对子 | 两张同点数，王可补 1 张（7+鬼=对7） |
| 顺子 | 3 张起连续，**不含 2**，王可补缺 |
| 连对 | 2 对起连续对子（3344），**不含 2**，王可补缺 |
| 炸弹 | **3 张起**同点数（三张即炸），王可补张数；上限 12 张 |

- **王不能单独打出**；双王/纯王组合不合法（至少 1 张真牌）
- **百搭顺子解析（确定性）**：先补内部缺口 → 从最高真牌向上延伸（不超 A）→ 从最低真牌向下延伸（不低于 3）。例：4,5,鬼,鬼→4567；K,A,鬼→QKA。2 永不作百搭目标

### 管牌（混合严宽）
- 单张/对子：**恰好大一级**（单3→单4，对5→对6）
- 例外：**2 无视 +1**——单2压任何单张、对2压任何对子；**仅炸弹可压 2**
- 顺子/连对：**同长度，起点必须落在上家牌型的点数窗口内**（不能跳远）：345 只能被 456/567 接，678 不能接；连对按对子粒度同理
- 炸弹可炸一切；炸对炸：**张数多的大，张数相同比点数**（4×5 > 3×K；3×2 > 3×A）

### 流程与记分
- 不能管：直接过不摸牌；**可以自愿过**（有牌能管也可选择过）
- 一轮结束（除出牌者外都过了）：出牌者摸 1 张，继续先出下一轮
- **出完手牌立即获胜**（即使别人还能压）
- **留 2 规则（2026-10-03 用户改稿）**：**禁止以单 2 或对 2 打完手牌**（2+鬼 也算对 2）——不判负、不淘汰，玩家留在局中（可继续被技能加牌等）；只剩单 2/对 2 时死锁守卫自动过、压不了就过牌；2 炸（3 张及以上 2）不受影响。本质是限制"留 2 随意压单牌"破坏体验，而非留 2 直接判负（原 2026-09-28 判负淘汰版本作废）
- 记分：**赢家 +(人数−1)，每个输家 −1**（零和；3 人局即 +2/−1/−1），无翻倍，跨局累计
- **再来一局**：终局后全员投票，全票通过 → 回到房间界面，可**重新选角色**、重新准备，房主开局（先手仍给上局赢家；2026-09-27 用户定稿）
- **流局**（规则未覆盖的边界，已按"平局"实现）：全员手牌只剩王/单 2（含 2026-10-03 留 2 改稿后的禁止收尾死锁）、无人能起牌时，无赢家、每人记 0 分，可再来一局。若用户线下有别的玩法可改（见 engine.finishDraw）

### 手牌上限与淘汰（已与用户逐条确认）
- **手牌上限 20 张**：不特殊说明时，所有人上限 20
- **超过 20 直接淘汰**：手牌进弃牌堆、记 −1、仅剩一人时该玩家立即获胜
- 座位保留但跳过（淘汰者不再轮到，仍显示在牌桌上）
- 角色技能造成的"判定牌"（如黑脸）当轮豁免上限，下轮重新计

### 技能相关通用规则（已与用户逐条确认）
- **大王红、小王黑**（涉及花色的技能判定以此为准）
- 插队（无名）：插队跳过了被响应者与无名之间的玩家；接完从**无名的下家**继续（2026-10-01 用户修正：原"被响应者下家"作废）；被响应者摸 X 张；插队适用于全部牌型（炸弹也适用）；2 人局无名就是下家，不触发插队
- 无名触发条件（2026-10-01 用户澄清）：**响应牌中有与被压的牌相同花色的真牌**即触发（单张也算，插队或普通响应均可）；X = **响应牌中同花色真牌的点数总和**（例：被压 ♠5♥6♦7、无名出 ♣6♦7♠8 → X = ♦7+♠8 = 15；♣6 不算）。原"响应牌含同花对子、X=解析后点数求和"作废
- 黑脸/观股的"牌权"= 轮末最后出牌者摸牌时刻（首局先手不算）
- 骚骚换牌**视为过牌**（2026-10-01 用户确认）：换牌取代出牌阶段、等同点过——其余人全过则本轮结束（最后出牌者摸 1 张并起新回合；2 人局即对方直接摸 1 张起新回合），否则轮到下家正常接牌
- 骚骚同花色选择（2026-10-01 用户确认）：**同花色也算同颜色**——同花色 2 张给牌时可自由选择换对方 1 张还是 2 张；仅同颜色（不同花色）只能换 2 张
- 巨石：驱逐 = 淘汰该出牌者 + 技能所有者获得牌权；驱逐优先于获胜判定；判定次数上限 = 玩家数+2；可选发动，放弃不消耗次数；判定失败判定牌摸回（当轮豁免手牌上限）；**触发按实体牌判断**——修勾答疑改点只改桌面判定点数，不改变「打出的是 2/炸弹」这一事实
- 修勾答疑：任何人（含自己）打出 ≥2 张的牌型（对/顺子/连对/炸）时可为其答疑——不改变牌型，把桌面这手牌的判定点数改为修勾任选的 3~A（顺子/连对改的是起点 = 最低点数）；牌面保留原牌但界面标注新点数；每回合（轮）限一次，弃权不消耗；只影响判定，实体牌不变
- 修勾狂吠：出牌后可以立刻按正常管牌规则压自己打出的牌（2 压一切等规则不变），可连压到放弃或压不了；同样受留 2/留 3 禁止收尾约束

## 技能优先原则（用户明确要求）

**技能与基础规则冲突时，技能生效。** 实现：引擎每个判定点走"基础规则校验 → 角色钩子覆写"两段管线——钩子可以 `allowAnyway` 放行基础规则禁止的动作，也可以 `ok:false` 否决基础规则允许的动作。引擎不做任何"哪个优先"的特判（详见 docs/04）。
